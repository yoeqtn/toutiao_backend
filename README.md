# 头条资讯 · 后端

FastAPI + SQLAlchemy(async) + PostgreSQL + LangChain / LangGraph。

## 安装依赖

项目使用 `uv` 管理虚拟环境（`.venv`）：

```bash
cd toutiao_backend
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
```

## 配置

- `.env`：模型配置（`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`）
- `config/db_conf.py`：PostgreSQL 连接串，默认
  `postgresql+asyncpg://postgres:postgres@localhost:5432/news_app`

## 启动

```bash
cd toutiao_backend
.venv/Scripts/python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

接口文档：`http://127.0.0.1:8000/docs`

## 数据库迁移

历史库中的 `user / user_token / favorite / history` 四张表，`id` 列缺少自增默认值，会导致注册、收藏、历史写入失败。已提供幂等修复脚本：

```bash
.venv/Scripts/python.exe - <<'PY'
import asyncio, pathlib, asyncpg
async def main():
    sql = pathlib.Path("migrations/001_fix_id_identity.sql").read_text(encoding="utf-8")
    conn = await asyncpg.connect("postgresql://postgres:postgres@localhost:5432/news_app")
    try:
        await conn.execute(sql)
    finally:
        await conn.close()
asyncio.run(main())
PY
```

该脚本只补充 `GENERATED BY DEFAULT AS IDENTITY`，不会改动已有数据，可重复执行。

## 本次联调修复

- `main.py`：加入前端开发服务器 CORS 白名单；建表改用各模型自身的 `Base.metadata`（原 `SQLModel.metadata` 为空，实际不会建表）。
- `models/users.py`：`gender` 由 PostgreSQL 枚举改为 `String(10)`，与现有数据库 `varchar` 列一致。
- `crud/history.py`：删除历史记录改为按 `history_id`（`History.id`）删除，并限定当前用户。
- `migrations/001_fix_id_identity.sql`：为缺少自增的四张表补充 IDENTITY。
